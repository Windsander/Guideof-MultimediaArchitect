
# 5.4 音视频帧处理实践（Audio & Video Frame Processing in Practice）

在 **5.2** 与 **5.3** 中，我们解决的是 "看懂" 帧的问题——切分、提取特征、分析帧间关系。而工程实践中，分析往往只是中间步骤，最终目的是 **按意图改变帧**：让声音更干净、让画面更鲜艳、让时长匹配需求。这就是 **帧处理（Frame Processing）**。

分析与处理是一组对偶的操作。分析是 **"帧 → 特征"** 的提取，处理则是 **"帧 → 修改 → 重建"** 的变换。有趣的是，二者共享同一套基础设施：5.2 的切帧与加窗，正是音频处理中 **重叠相加重建（OLA）** 的前奏；5.3 的逐帧遍历，则是视频批量滤镜的骨架。理解了分析，处理不过是 "在流水线上多挂几个环节"。

本节将沿着 **"音频怎么处理 → 视频怎么处理 → 动手做一遍"** 的路线递进展开：

- **[5.4.1 音频帧处理：滤波、变速与变调](Docs_5_4_1.md)**：从 Butterworth 低通滤波，到相位声码器支撑的变速不变调与变调
- **[5.4.2 视频帧处理：色彩、滤波与几何变换](Docs_5_4_2.md)**：HSV 色彩调整、高斯模糊与 USM 锐化、几何变换，以及逐帧处理的实时性预算
- **[5.4.3 实战：音视频帧批量处理工程](Docs_5_4_3.md)**：搭建音频与视频两条处理管线，对真实素材与测试视频执行批量处理并对比验证

完成本节后，第五章 "概念 → 工具 → 分析 → 处理" 的闭环就完整了——我们将具备对音视频素材进行 **帧级加工** 的完整能力，也就是剪辑软件、滤镜 App、实时通话处理等日常音视频产品的技术内核。
