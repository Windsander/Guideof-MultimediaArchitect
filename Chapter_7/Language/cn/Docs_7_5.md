
# 7.5 现代协议群像：DASH、WebRTC 与 SRT（The Modern Protocol Landscape）

7.4 节讲完 HLS，自适应流的天下却只占了一半。同一个年代里，三条路线各自开花结果：MPEG 用国际标准回应 Apple 的私有方案，Google 把 RTP 的血缘锻造成浏览器里的实时通话，Haivision 则为公网弱网回传开出了 ARQ 的药方。本节把这群现代主角请上同一舞台，最后以一幅编年史长卷收束第七章的协议巡礼。

- **[7.5.1 DASH：标准化的另一极](Docs_7_5_1.md)**：MPD 的单文件层级；SegmentTemplate 的寻址艺术；CMAF 促成的大合流
- **[7.5.2 WebRTC：RTP 的正统继承者](Docs_7_5_2.md)**：全部由既有协议组合而成的协议栈；信令留白的深意；毫秒级互动的代价
- **[7.5.3 SRT：弱网回传的 ARQ 路线](Docs_7_5_3.md)**：TSBPD 恒定延迟重构；Too-Late Packet Drop 的直播取向；与 RTMP 的角色对位
- **[7.5.4 编年史与全景对照](Docs_7_5_4.md)**：1996~2019 的五代协议长卷；六维对照表；技术演进的内在逻辑

完成本节后，第七章的理论版图就已拼齐，7.6 节我们将亲手推流、抓包、拉流，用两个实验把整章知识落到字节上。
